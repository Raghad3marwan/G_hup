# جنايات — الموت الذي بدا طبيعيًا

نسخة اللعبة المبنية من ملفات المراجعة الأربعة المعتمدة.

## التشغيل
يفضل تشغيل اللعبة عبر خادم محلي صغير لأن المتصفحات قد تمنع تحميل ملفات JavaScript عند فتح `index.html` مباشرة من القرص.

### macOS
انقر مرتين على `START_GAME.command`، أو افتح Terminal داخل المجلد وشغّل:

```bash
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080/index.html`.

### Windows
شغّل `START_GAME.bat`.

## قواعد القضية المجمدة
- 11 عائلة أدلة فقط: E01–E11.
- A01 وA02 طلبا فحص داخل مسار الأدلة، وليسا بطاقتي دليل إضافيتين.
- G01 يعتمد على M01 + M02 + M04 + M05 + M08 + M09.
- M03 ليس شرطًا لفتح G01، لكنه شرط لإرسال الحل النهائي.
- الاستجوابات والمواجهات داعمة وليست شرطًا لفتح G01.
- لا كاميرا داخل غرفة 02 ولا كاميرا ترى بابها مباشرة.
- لا يوجد سجل دخول إلكتروني لباب غرفة 02.
- لا تعرض اللعبة جرعات أو خطوات تنفيذية للتسبب بالوفاة.
